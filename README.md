# Portfolio

Portfolio personnel de **Yohan Baechlé**, développé avec **React 19**,
**TypeScript** et **Vite**.

> 🚧 **En cours de développement** — la base du projet est en place ; le contenu
> et les sections (présentation, projets, contact) sont en construction.

## Stack technique

- **React 19**
- **TypeScript 5**
- **Vite 7** (`@vitejs/plugin-react-swc`)
- **ESLint** (react-hooks, react-refresh)

## Mise en route

Prérequis : Node.js 18+.

```bash
npm install
npm run dev      # serveur de développement (http://localhost:5173)
npm run build    # build de production
npm run preview  # prévisualiser le build
```
